# Image sources

- Lifestyle photos (hero, categories/mattresses, categories/bunk-beds, showroom, kids-room, landlords, paths/*):
  Unsplash (https://unsplash.com), used under the Unsplash licence (free to use, attribution appreciated but not required).
  `showroom.jpg` is a stock photo of a mattress showroom, NOT the Discount Beds Belfast showroom. Replace it with your own photo.
- Category, product, team and logo images: downloaded from the current https://www.discountbedsbelfast.co.uk site (the shop's own content).
  Product photos are supplier images as used on the existing site.
- Payment logos: Simple Icons (https://simpleicons.org), CC0. The Visa, Mastercard and PayPal marks remain trademarks of their owners.
- Replace any file with a better one using the same name (for example `hero.jpg`), then run `python build/build.py`.
